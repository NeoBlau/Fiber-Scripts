# Инструкция

Программа раскладывает изменение показателя (выручки, прибыли, рентабельности…) на влияние факторов
и рисует графики. Нужен только R, всё остальное скачается само.

---

## 1. Установка (один раз)

1. Установите **R**: https://cran.r-project.org
   - Windows: «Download R for Windows» → «base» → скачать → установить (везде «Далее»).
   - Mac: «Download R for macOS» → файл `.pkg` (для M1/M2/M3/M4 — `arm64`).
2. Установите **RStudio**: https://posit.co/download/rstudio-desktop/
3. Откройте **RStudio** и вставьте в консоль (окно внизу слева) этот код, затем нажмите Enter:

```r
url <- "https://github.com/NeoBlau/Fiber-Scripts/archive/refs/heads/claude/deterministic-factor-analysis-r-pnfmty.zip"
dir <- file.path(path.expand("~"), "DFA"); dir.create(dir, showWarnings = FALSE)
download.file(url, file.path(dir, "dfa.zip"), mode = "wb"); unzip(file.path(dir, "dfa.zip"), exdir = dir)
source(file.path(dir, "Fiber-Scripts-claude-deterministic-factor-analysis-r-pnfmty", "START.R"), encoding = "UTF-8")
```

Программа скачается в папку `DFA` (Windows: `Документы\DFA`, Mac: `/Users/имя/DFA`), и появится меню.
Этот же код обновляет программу до новой версии.

---

## 2. Как пользоваться

Всё управление — через меню. Введите номер и нажмите Enter:

```
Детерминированный факторный анализ. Что сделать?
1: Анализ моих данных (пошаговый мастер: выбрать файл → указать модель → готово)
2: Проверка на случайных данных (убедиться, что всё работает)
3: Посмотреть пример (демо-данные)
4: Повторить прошлый анализ моих данных
5: Окно настроек со всеми параметрами (на Mac нужен XQuartz)
6: Выход
```

**Первый раз** выберите `2`: программа проверит себя на случайных данных. В конце должно быть «Всё сошлось».

**В следующий раз** откройте в RStudio файл `DFA/Fiber-Scripts-…/START.R`
(File → Open File…) и нажмите кнопку **Source** над кодом. Появится то же меню.

## 3. Свои данные

### 3.1. Как оформить таблицу

Сделайте таблицу в Excel: **строка = период, столбец = показатель**. В первой строке — названия столбцов.

**Два периода (план/факт, прошлый/текущий год):**

| period | Q     | Pr  | V   | FC      |
|--------|-------|-----|-----|---------|
| План   | 12000 | 850 | 520 | 2100000 |
| Факт   | 12800 | 870 | 545 | 2250000 |

**Несколько лет или месяцев** — просто больше строк:

| year | CR  | D   | P   | CV   |
|------|-----|-----|-----|------|
| 2023 | 100 | 250 | 7.8 | 0.25 |
| 2024 | 104 | 245 | 7.7 | 0.27 |
| 2025 | 108 | 248 | 7.9 | 0.28 |

**Несколько филиалов / магазинов / товаров** — добавьте столбец с их названиями:

| branch | period | N    | AC   | FR  |
|--------|--------|------|------|-----|
| Москва | 2024   | 5200 | 1.45 | 3.1 |
| Москва | 2025   | 5600 | 1.52 | 3.0 |
| Казань | 2024   | 2100 | 1.20 | 2.8 |
| Казань | 2025   | 2350 | 1.18 | 3.1 |

**Правила:**
- **Названия столбцов-показателей** — короткие, латиницей, без пробелов: `Q`, `Price`, `cost_1`.
  Русские названия для графиков мастер спросит отдельно.
- **Числа** — как обычно в Excel: `1 234,5`, `1234.5`, `12,5%`, `(1 234)` (минус в скобках), `−5` —
  всё понимается. Годы можно писать числом (`2024`) или текстом.
- **Пустых ячеек** в показателях быть не должно.
- Столбец с результатом (например, прибыль) **не нужен**: программа посчитает его по формуле.

**Сохранение из Excel:** «Файл → Сохранить как → CSV UTF-8» (или просто «CSV»). Файлы `.xlsx` тоже
подходят, но для них один раз выполните в консоли `install.packages("readxl")`.

Готовые образцы лежат в папке `examples`: `template_my_data.csv`, `example_periods.csv`,
`example_groups.csv`. Можно открыть их в Excel и заменить цифры на свои.

### 3.2. Запуск

Меню → `1`. Мастер задаст 5 вопросов:

1. **Файл** — откроется обычное окно выбора файла.
2. **Где периоды** — выберите номер столбца (например, `period` или `year`).
3. **Есть ли филиалы/объекты** — если в таблице есть такой столбец.
4. **Модель** — формула, как результат считается из ваших столбцов (см. ниже).
5. **Русские названия** — по желанию, для подписей на графиках.

Результаты сохранятся **в папку рядом с вашим файлом**: `DFA_<имя файла>`.

### 3.3. Как записать модель

Пишется как формула в Excel, только с названиями столбцов:

| Что анализируете | Модель |
|---|---|
| Выручка = численность × дни × часы × выработка | `V = CR * D * P * CV` |
| Прибыль = объём × (цена − перем. затраты) − пост. затраты | `PR = Q * (Pr - V) - FC` |
| Рентабельность активов, % | `R = P / (F + E) * 100` |
| Себестоимость = сумма статей | `C = M + W + A + O` |
| ROE по Дюпону | `ROE = NPM * AT * EM * 100` |

Слева от `=` — любое имя результата, справа — названия столбцов и знаки `+ - * / ( )`.
Регистр букв важен: `Pr` и `pr` — разные названия.

## 4. Результат

### 4.1. Графики на экране

После расчёта графики появляются в RStudio во вкладке **Plots** (справа внизу):
стрелки **← →** — листать, **Zoom** — во весь экран, **Export** — сохранить картинку.

Показываются 5 главных графиков — этого достаточно для выводов:

| График | Что показывает |
|---|---|
| **Сводная панель** | 4 графика на одном листе: водопад, доли факторов, сравнение методов, темпы роста. Для отчёта или презентации |
| **Каскадная диаграмма (водопад)** | Как показатель изменился от базы к отчёту: зелёные столбики — факторы, которые его увеличили, красные — уменьшили. **Главный график** |
| **Сравнение методов** | Влияние каждого фактора, посчитанное разными методами. Если столбики почти одинаковые, выводы надёжные |
| **Чувствительность к порядку** | Насколько результат метода цепных подстановок зависит от порядка факторов. Широкая серая полоса — лучше опираться на интегральный метод |
| **Торнадо** | Что будет с результатом, если каждый фактор изменить на ±10 %. Самый длинный столбик — самый «сильный» фактор |

Для нескольких периодов добавляются: вклад факторов **по периодам**, **динамика** результата и
**тепловая карта**. Для филиалов — сравнение **филиалов** между собой.

Всего видов графиков 13. Остальные (доли, эластичности, цепочка подстановок, темпы роста) лежат в PDF.
Показать все на экране: `dfa_show(res, mode = "all")`. Показать снова только главные: `dfa_show(res)`.

### 4.2. Файлы

В папке результатов:

| Файл | Что это |
|---|---|
| `dfa_report.txt` | Отчёт: таблицы, формулы, выводы простым текстом — **начните с него** |
| `dfa_plots.pdf` | Все графики в одном файле |
| `plots/` | Графики картинками PNG (для Word и PowerPoint) |
| `tables/` | Таблицы CSV — открываются в Excel |
| `settings.R` | Сохранённые настройки (нужны для пункта 4 меню) |

## 5. Если что-то не так

| Проблема | Решение |
|---|---|
| «В файле нет столбцов: …» | Названия в формуле не совпадают с заголовками таблицы. Программа покажет, какие столбцы есть, и подскажет похожее (`Q → «q»?`) |
| «…значения, которые не являются числами: «n/a»» | В ячейке текст вместо числа — исправьте указанную строку таблицы |
| «Интеграл не существует…» | Знаменатель модели меняет знак между базой и отчётом. Это не ошибка программы — используйте цепные подстановки или Шепли (они посчитаны) |
| В таблице все числа попали в один столбец | Файл сохранён с необычным разделителем — пересохраните из Excel как «CSV UTF-8» |
| «Модель не вычисляется» | В данных деление на ноль или пустая ячейка |
| Русские буквы — «кракозябры» | Обновите R (на Windows нужна версия 4.2 или новее) |
| Mac: предупреждения `R_X11.so` / `libSM.6.dylib` | Обновите программу (код из пункта 1). На расчёты это не влияет |
| Пункт 5 меню (окно) не открывается на Mac | Установите XQuartz: https://www.xquartz.org, перезагрузите Mac. Пункты 1–4 работают и без него |
| Меню пропало | Введите в консоли `dfa_start()` |

## Для продвинутых

Одной командой, без меню:

```r
res <- dfa("C:/Users/Иван/Documents/данные.csv", "PR = Q * (Pr - V) - FC")   # на Windows — прямые слэши /
dfa_show(res)
```

Все параметры (методы, порядок подстановки, цвета, форматы) описаны в [README.md](README.md).
