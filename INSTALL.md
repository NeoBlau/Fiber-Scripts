# Установка и первый запуск

Скрипту нужен только R. Дополнительные пакеты ставить не нужно: всё работает на базовом R.

## Шаг 1. Установите R (один раз)

1. **R** — https://cran.r-project.org
   - Windows: «Download R for Windows» → «base» → «Download R-x.x.x for Windows», запустить установщик, везде «Далее».
   - macOS: «Download R for macOS» → выбрать `.pkg` под ваш процессор (Apple Silicon — `arm64`, Intel — `x86_64`).
   - Linux (Ubuntu/Debian): `sudo apt install r-base`
2. **RStudio** (по желанию, удобнее работать) — https://posit.co/download/rstudio-desktop/
3. **Только для macOS**: для окна настроек нужен XQuartz — https://www.xquartz.org.
   Без него расчёты и графики работают, но окно не откроется.

Для кириллицы на Windows нужен R версии 4.2 или новее.

## Шаг 2. Скачайте проект и проверьте его на случайных данных

Откройте R или RStudio, вставьте код в консоль и нажмите Enter:

```r
url <- "https://github.com/NeoBlau/Fiber-Scripts/archive/refs/heads/claude/deterministic-factor-analysis-r-pnfmty.zip"
dir <- file.path(path.expand("~"), "DFA")
dir.create(dir, showWarnings = FALSE)
zip <- file.path(dir, "dfa.zip")
download.file(url, zip, mode = "wb")
unzip(zip, exdir = dir)
setwd(file.path(dir, "Fiber-Scripts-claude-deterministic-factor-analysis-r-pnfmty"))
source("examples/run_random_test.R", encoding = "UTF-8")
```

Что произойдёт:

1. Проект скачается в папку `DFA` в домашней папке (на Windows обычно `Документы\DFA`).
2. Сгенерируются 3 случайных набора данных: смешанная модель (план/факт), мультипликативная (6 лет),
   кратная (5 филиалов).
3. По каждому пройдёт анализ, в конце появится итог:

```
================ ИТОГ ПРОВЕРКИ ================
1. Смешанная, план/факт расчётов:  1 | методов: 5 | баланс: OK | файлов: 20
2. Мультипликат., 6 лет расчётов:  5 | методов: 7 | баланс: OK | файлов: 24
3. Кратная, 5 филиалов расчётов:  5 | методов: 5 | баланс: OK | файлов: 13

Всё сошлось.
```

Результаты — отчёты, таблицы CSV, графики PNG и общий PDF — лежат в папке `dfa_random_test`
внутри проекта. Путь к проекту покажет команда `getwd()`.

Другие случайные данные: откройте `examples/run_random_test.R` и поменяйте `SEED` в начале файла.

## Шаг 3. Окно настроек

В той же консоли, после шага 2:

```r
DFA_NO_RUN <- TRUE
source("deterministic_factor_analysis.R", encoding = "UTF-8")
dfa_gui()
```

Откроется окно с вкладками. В нём можно:
- выбрать демо-набор или свой файл (CSV / Excel);
- ввести модель и нажать «Проверить модель»;
- настроить методы, подписи и графики;
- нажать «Запустить анализ».

Отчёт появится на вкладке «Журнал / отчёт», графики откроются кнопкой «Открыть PDF».

## Шаг 4. Анализ на своих данных

### 4.1. Подготовьте таблицу

Самый простой способ — Excel. Одна строка = один период, один столбец = один фактор:

| period | Q     | Pr  | V   | FC      |
|--------|-------|-----|-----|---------|
| План   | 12000 | 850 | 520 | 2100000 |
| Факт   | 12800 | 870 | 545 | 2250000 |

Правила:
- **Названия факторов** — короткие, латиницей, без пробелов: `Q`, `Pr`, `V`, `FC`, `price`, `cost_var`.
  Русские расшифровки задаются отдельно, в подписях.
- **Периодов может быть сколько угодно**: 2 (план/факт, прошлый/текущий год) или ряд лет и месяцев.
  При 3 и более периодах по умолчанию считается цепная схема (каждый период к предыдущему) плюс итог за весь срок.
- **Несколько объектов** (филиалы, магазины, товары) — добавьте столбец, например `branch`, и дайте
  каждому объекту свои строки с периодами. Пример: `examples/example_groups.csv`.
- Столбец с самим результатом (например, `PR`) можно не добавлять: скрипт посчитает его по модели.
  Если он есть, скрипт сверит его с моделью и покажет расхождения.
- Можно и «перевёрнутую» таблицу: строки = факторы, столбцы = периоды. Скрипт определит это сам.
  Пример: `examples/example_long.csv`.

Сохраните таблицу: в Excel «Файл → Сохранить как → **CSV UTF-8 (разделитель — запятая)**» или обычный
«CSV (разделитель — точка с запятой)». Разделитель, десятичную запятую и пробелы в тысячах скрипт
распознаёт сам. Если русские буквы в файле «поехали», укажите кодировку `CP1251`: поле «Кодировка»
в окне или `encoding = "CP1251"` в коде. Файлы `.xlsx` тоже читаются, если установлен пакет `readxl`.

Готовый шаблон: `examples/template_my_data.csv`.

### 4.2. Запишите модель

Модель — это формула из названий ваших столбцов:

| Что анализируете | Модель |
|---|---|
| Выручка = численность × дни × часы × выработка | `V = CR * D * P * CV` |
| Прибыль = объём × (цена − перем. затраты) − пост. затраты | `PR = Q * (Pr - V) - FC` |
| Рентабельность активов, % | `R = P / (F + E) * 100` |
| Себестоимость = сумма статей | `C = M + W + A + O` |
| ROE по Дюпону | `ROE = NPM * AT * EM * 100` |

Можно использовать `+ - * / ^ ( )` и функции R (`log`, `exp`, `sqrt` …).

### 4.3. Запустите — любым из трёх способов

**Способ А — через окно (проще всего).**
```r
DFA_NO_RUN <- TRUE
source("deterministic_factor_analysis.R", encoding = "UTF-8")
dfa_gui()
```
В окне:
1. Вкладка «1. Данные»: выберите «Файл», нажмите «Обзор…» и укажите ваш CSV. Ниже появится
   предпросмотр, проверьте столбец периодов.
2. Вкладка «2. Модель»: впишите модель, заполните «Название результата» и нажмите «Проверить модель».
3. Вкладка «3. Факторы»: впишите русские подписи факторов.
4. Нажмите «▶ Запустить анализ», затем «Открыть PDF».
5. «Сохранить конфиг…» — чтобы в следующий раз не вводить всё заново («Загрузить конфиг…»).

Данные можно вбить и прямо в окне: вкладка «2. Модель» → впишите модель → вкладка «1. Данные» →
«Новая таблица по модели…» — откроется таблица с нужными столбцами.

**Способ Б — через файл-заготовку.**
Откройте `examples/run_my_data.R` в RStudio и поменяйте блок «НАСТРОЙКИ» (путь к файлу, модель,
подписи). Затем нажмите **Source**. Файл удобно скопировать под каждую свою задачу.

**Способ В — одной строкой в консоли R.**
```r
DFA_NO_RUN <- TRUE
source("deterministic_factor_analysis.R", encoding = "UTF-8")

res <- dfa_run(list(
  demo       = NULL,
  data_file  = "C:/Users/Иван/Documents/мои_данные.csv",   # прямые слэши!
  model      = "PR = Q * (Pr - V) - FC",
  period_col = "period",
  response_label = "Прибыль от продаж, руб.",
  factor_labels  = c(Q = "Объём, шт.", Pr = "Цена, руб.", V = "Перем. затраты, руб.", FC = "Пост. затраты, руб."),
  output_dir = "мой_анализ"
))
```
Или сразу из таблицы, которая уже загружена в R:
```r
res <- dfa_analyze("PR = Q * (Pr - V) - FC", data = my_df, period_col = "period")
```

### 4.4. Графики прямо в RStudio

После расчёта главные графики сами появляются во вкладке **Plots** (справа внизу в RStudio):
- стрелки **← →** листают графики;
- **Zoom** открывает график во весь экран;
- **Export** сохраняет картинку.

Вызвать графики снова:
```r
dfa_show(res)                         # главные: сводные панели и итоговые графики
dfa_show(res, mode = "all")           # все графики
dfa_show(res, "waterfall")            # только водопады (поиск по части имени)
dfa_show(res, c("tornado", "order"))  # несколько видов
dfa_show(res, list = TRUE)            # список всех графиков
```
Для проверочного скрипта: `dfa_show(res1)`, `dfa_show(res2)`, `dfa_show(res3)`. В окне настроек
для этого есть кнопка «Показать графики».

Настройка `show_plots`: `"main"` (по умолчанию), `"all"` или `"none"`, например
`dfa_run(list(..., show_plots = "all"))`. При запуске через `Rscript` графики только сохраняются в файлы.

### 4.5. Где результат

Результат лежит в папке `output_dir` (по умолчанию `dfa_output`):

| Файл | Что внутри |
|---|---|
| `dfa_report.txt` | полный отчёт с выводами |
| `dfa_plots.pdf` | все графики в одном файле |
| `plots/*.png` | графики по отдельности (для презентаций) |
| `tables/*.csv` | таблицы, открываются в Excel |
| `dfa_results.xlsx` | всё в одном Excel-файле (если установлен `openxlsx`) |

Типичные ошибки на своих данных:
- «В данных нет столбцов для факторов» — названия в модели и в файле должны совпадать буква в букву,
  с учётом регистра (`Pr` ≠ `pr`).
- «Модель не вычисляется» — где-то деление на ноль или пустая ячейка.
- «Для анализа нужно минимум 2 периода» — проверьте, что столбец периодов указан верно.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Ошибка при `download.file` | Проверьте интернет, прокси или антивирус. Или скачайте ZIP вручную по ссылке из первой строки кода, распакуйте в `Документы\DFA` и выполните только две последние строки кода. |
| `cannot change working directory` | Папка называется иначе: выполните `list.files(dir)` и подставьте имя в `setwd(...)`. |
| Вместо русских букв «кракозябры» | Обновите R до 4.2+ (Windows) и вызывайте `source(..., encoding = "UTF-8")`. |
| macOS: `There were N warnings` с текстом `unable to load shared object ... R_X11.so` / `libSM.6.dylib` | Это не ошибка расчёта: R ищет XQuartz для графики. Скачайте свежую версию (код из шага 2), в ней графики на Mac рисуются встроенным движком Quartz. Или установите XQuartz — он всё равно нужен для окна настроек. |
| Окно настроек не открывается (macOS) | Установите XQuartz и перезапустите R. |
| Окно не открывается (RStudio Server, удалённый сервер) | Там нет графического экрана. Используйте `dfa_edit_config()` или конфиг-файл: `Rscript deterministic_factor_analysis.R --config=examples/my_config.R` |
| Нужен Excel на выходе | `install.packages("openxlsx")` — после этого появится `dfa_results.xlsx`. |
| Нужно читать `.xlsx` на входе | `install.packages("readxl")` (или сохраните файл из Excel как CSV). |
