FIBER PULSE В YANDEX DATALENS
=============================

Вся программа Fiber Pulse — одним чартом внутри DataLens:

  Обзор               итог, к прошлому месяцу и году, растущие/падающие позиции,
                      динамика с прошлым годом, выводы, мост, лидеры, структура
  Позиции             таблица с динамикой, изменениями и долями, сортировка
  Карта изменений     позиции × периоды: где и когда был рост или падение
  Карточка позиции    история, сезонность «год к году», таблица по годам,
                      темп роста, стабильность, другие показатели позиции
  Факторы             детерминированный факторный анализ восемью методами:
                      цепных подстановок, абсолютных разниц, относительных разниц,
                      индексный, интегральный, логарифмический, Шепли,
                      пропорционального деления — с проверкой баланса, выводами,
                      расчётом «как в учебнике», устойчивостью и эластичностями
  Прогноз и сценарии  прогноз на 3–24 месяца с интервалом, сценарии «что если»
                      по всем позициям и по группам

Сверху — переключатели: показатель, группа, период (‹ ›), сравнение
(к пред. периоду / к году назад), шаг (месяцы / кварталы / годы).
Расчёт идёт на сервере DataLens, данные никуда не уходят.


САМЫЙ ПРОСТОЙ СПОСОБ УСТАНОВКИ — ЧЕРЕЗ ПРОГРАММУ FIBER PULSE
------------------------------------------------------------

1. Откройте FiberPulse.html, загрузите свою таблицу (или test_data/pub_sales.csv).
2. Слева — раздел «В DataLens». Там 4 шага, программа всё заполнит сама:
   * «Скачать CSV для DataLens» — файл, который точно подойдёт плагину;
   * в DataLens: «Создать» → «Подключение» → «Файлы» → загрузить этот CSV →
     «Создать датасет» → у цен поставить агрегацию «Среднее» → «Сохранить»;
   * вставить адрес сохранённого датасета в программу;
   * в DataLens: «Создать» → «Чарт в Editor» → «Продвинутый чарт»;
     в каждой из 4 вкладок (Meta, Params, Sources, Prepare) — Ctrl+A,
     нажать в программе соответствующую кнопку «копировать», Ctrl+V.
3. «Выполнить» → «Сохранить». Готово.

Названия полей, список показателей, формулу и ID датасета программа
подставит сама — ничего вручную править не нужно.


РУЧНАЯ УСТАНОВКА (без программы)
--------------------------------

  1_Meta.json                    → вкладка Meta (ID датасета)
  2_Params.js                    → вкладка Params (все настройки)
  3_Sources.js                   → вкладка Sources (менять не нужно)
  4_Prepare_FactorAnalysis.js    → вкладка Prepare (вся программа)
  5_Prepare_Table.js             → Prepare отдельного чарта-таблицы (по желанию)
  test_data/pub_sales.csv        тестовые данные паба

1. Загрузите test_data/pub_sales.csv как подключение «Файлы» (разделитель «;»,
   UTF-8), создайте датасет: «Месяц» — дата, «Цена, руб.» — агрегация «Среднее»,
   остальные числа — «Сумма». Сохраните датасет.
2. ID датасета — часть адреса после /datasets/ до дефиса.
   Адрес вида …/datasets/new?id=… — это ещё НЕ сохранённый датасет (там ID
   подключения): сначала нажмите «Сохранить».
3. «Создать» → «Чарт в Editor» → «Продвинутый чарт», вставьте файлы 1–4
   целиком во вкладки, в Meta впишите ID. «Выполнить».
   Должно получиться: Выручка, руб.: дек 2025 — 13,2 млн, +13,0% к дек 2024.

Чарт-таблица (по желанию): «Чарт в Editor» → «Таблица», те же Meta, Params,
Sources и 5_Prepare_Table.js — влияние факторов по каждой позиции с
сортировкой и выгрузкой в Excel.


НАСТРОЙКИ (вкладка Params)
--------------------------

Названия полей пишите ТОЧНО как в датасете.

  fa_period        поле периода: дата, «2025-01», «янв 2025», «I кв 2025», «2025»
  fa_position      поле позиции (товар, статья, филиал). [''] — только итог
  fa_group         поле группы. [''] — без групп
  fa_metrics       числовые поля-показатели через «;» (до 8)
  fa_metric        какой показатель открыт сначала
  fa_grain         шаг: M — месяцы, Q — кварталы, Y — годы
  fa_formula       модель для факторного анализа из полей в [квадратных скобках]
  fa_result_name   как называть результат
  fa_avg_fields    поля, которые усредняются, а не суммируются (цены, доли), через «;»
  fa_compare       yoy — к тому же периоду год назад, prev — к предыдущему,
                   custom — к периоду из fa_period_a
  fa_period_b      отчётный период: last или, например, 2025-12
  fa_period_a      базисный период для custom, например 2024-06
  fa_method        метод факторного анализа по умолчанию:
                   chain, abs, rel, index, integral, log, shapley, prop
  fa_order         порядок подстановки: названия факторов через «;»
  fa_group_filter  только одна группа (пусто — все)

Примеры формул:
  [Продано, шт.] * [Цена, руб.]                            выручка (произведение)
  [Выручка, руб.] - [Себестоимость, руб.]                  маржа (сумма)
  [Выручка, руб.] / [Продано, шт.]                         средняя цена (кратная)
  [Объём] * ([Цена] - [Перем. затраты]) - [Пост. затраты]  прибыль (смешанная)

Любой параметр можно вынести на дашборд селектором с тем же именем
(например, fa_metric или fa_group_filter).


ОГРАНИЧЕНИЯ
-----------

* DataLens даёт серверному расчёту до 10 секунд. Проверено на макете:
  2000 позиций × 36 месяцев × 6 показателей — около 5 с, 3000 позиций с формулой
  из 6 факторов — около 9 с. Если данных больше — выберите группу или
  уменьшите число показателей в fa_metrics.
* Внутри чарта DataLens нельзя делать поля ввода и выпадающие списки — всё
  переключается кнопками. Формула и поля меняются на вкладке Params.
* Таблица «Позиции» показывает 150 крупнейших позиций, карта изменений — 120,
  карточки — 80 крупнейших; итоги, выводы и факторный анализ считаются по всем.
* В живом DataLens плагин мной не запускался — проверен на макете DataLens
  (те же функции Editor, ограничения тегов и времени). Если что-то не
  заработает, пришлите текст ошибки.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------

* «В датасете нет полей: …» — название в Params не совпадает с датасетом.
  Ошибка перечисляет поля, которые есть.
* «Датасет вернул 0 строк» — неверный ID в Meta или нет доступа.
* «Не удалось распознать периоды» — сделайте поле периода типом «Дата».
* «Нет данных для периода сравнения» — нажмите «к пред. месяцу».
* Странные суммы цен — у цены в датасете агрегация «Сумма»; поставьте «Среднее».

Исходники: tools/datalens/ (core.js — факторный анализ, app_core.js — остальные
разделы, tail_chart.js — отрисовка). Сборка: node tools/datalens/build.js —
она же обновляет код, встроенный в FiberPulse.html.
