ФАКТОРНЫЙ АНАЛИЗ ДЛЯ YANDEX DATALENS (плагин Fiber Pulse)
=========================================================

Готовый чарт для DataLens, который раскладывает изменение показателя
(выручки, маржи, затрат — чего угодно) на влияние факторов восемью методами
детерминированного факторного анализа:

    1. цепных подстановок        5. интегральный
    2. абсолютных разниц         6. логарифмический
    3. относительных разниц      7. Шепли (взвешенных конечных разностей)
    4. индексный                 8. пропорционального деления

Работает с любым датасетом DataLens: вы указываете названия полей и формулу,
остальное плагин делает сам. Расчёт идёт на сервере DataLens, данные никуда
не уходят.


ЧТО В ПАПКЕ
-----------

  1_Meta.json                    → вкладка Meta (связь с датасетом)
  2_Params.js                    → вкладка Params (ВСЕ настройки — здесь)
  3_Sources.js                   → вкладка Sources (менять не нужно)
  4_Prepare_FactorAnalysis.js    → вкладка Prepare основного чарта
  5_Prepare_Table.js             → вкладка Prepare чарта-таблицы (по желанию)
  test_data/pub_sales.csv        тестовые данные паба, чтобы проверить

Файлы 4 и 5 собираются из tools/datalens/ командой: node tools/datalens/build.js
(нужно только если вы правите исходники; готовые файлы уже лежат здесь).


ЧТО НУЖНО
---------

* Доступ к DataLens с возможностью создавать чарты в Editor
  (пункт «Создать → Чарт в Editor»). Если такого пункта нет — Editor
  выключен в вашей организации, попросите администратора его включить.
* Датасет, в котором есть: поле периода (дата или месяц), поле позиции
  (необязательно) и числовые поля-факторы.


УСТАНОВКА ЗА 10 МИНУТ (на тестовых данных)
------------------------------------------

Шаг 1. Загрузить данные.
   DataLens → «Создать» → «Подключение» → «Файлы» → загрузите
   test_data/pub_sales.csv. Разделитель — точка с запятой, кодировка UTF-8.
   Проверьте, что «Месяц» распознан как дата, а «Продано, шт.» и
   «Цена, руб.» — как числа. Сохраните подключение.

Шаг 2. Создать датасет.
   На подключении нажмите «Создать датасет». Во вкладке «Поля»:
   * «Месяц» — тип «Дата», измерение;
   * «Позиция», «Группа» — измерения (строки);
   * «Продано, шт.» — показатель, агрегация «Сумма»;
   * «Цена, руб.» — показатель, агрегация «Среднее»  ← важно!
     Цену нельзя складывать: если в датасете несколько строк на позицию
     в месяц, сумма цен даст ерунду.
   Сохраните датасет.

Шаг 3. Узнать ID датасета.
   Откройте датасет: ID — это часть адреса после /datasets/
   (например, в https://datalens.yandex.cloud/datasets/abc123def456 ID = abc123def456;
   если в адресе есть «-название», берите только часть до дефиса).

Шаг 4. Создать чарт.
   «Создать» → «Чарт в Editor» → тип «Продвинутый чарт» (Advanced chart).
   У чарта есть вкладки Meta, Params, Sources, Prepare. В каждую вставьте
   содержимое соответствующего файла ЦЕЛИКОМ, заменив то, что там было:
     Meta     ← 1_Meta.json  (вместо ВСТАВЬТЕ_ID_ДАТАСЕТА — ваш ID из шага 3)
     Params   ← 2_Params.js
     Sources  ← 3_Sources.js
     Prepare  ← 4_Prepare_FactorAnalysis.js
   Нажмите «Выполнить». Должно получиться:
     Выручка, руб.: дек 2024 → дек 2025 — 11,7 млн → 13,2 млн, +1,52 млн (+13%).
   Сохраните чарт.

Шаг 5 (по желанию). Таблица для Excel.
   «Создать» → «Чарт в Editor» → «Таблица». Те же Meta, Params, Sources,
   а в Prepare — 5_Prepare_Table.js. Получите таблицу «позиция × влияние
   каждого фактора» с сортировкой и выгрузкой в Excel/CSV.

Шаг 6 (по желанию). Дашборд.
   Добавьте чарт(ы) на дашборд. Любую настройку из Params можно вывести
   селектором: добавьте селектор «Ручной ввод», в поле «Имя параметра»
   впишите, например, fa_method и задайте значения
   chain, abs, rel, index, integral, log, shapley, prop. Селектор с тем же
   именем управляет и графиком, и таблицей сразу.
   Полезные селекторы: fa_method, fa_compare (prev / yoy), fa_period_b,
   fa_group_filter (название группы, пусто — все).


СВОИ ДАННЫЕ
-----------

Всё настраивается на вкладке Params. Названия полей пишите ТОЧНО как в датасете.

  fa_period        поле периода: дата, «2025-01», «янв 2025», «I кв 2025», «2025»
  fa_position      поле позиции (товар, статья, филиал). [''] — анализ только итога
  fa_group         поле группы. [''] — без групп
  fa_formula       модель результата из полей в [квадратных скобках]
  fa_result_name   как называть результат в отчёте
  fa_avg_fields    поля, которые при сложении строк усредняются (цены, доли), через ;
  fa_compare       yoy — к тому же периоду год назад, prev — к предыдущему,
                   custom — к периоду из fa_period_a
  fa_period_b      отчётный период: last или, например, 2025-12
  fa_period_a      базисный период для custom, например 2024-06
  fa_method        основной метод: chain, abs, rel, index, integral, log, shapley, prop
  fa_order         порядок подстановки: названия факторов через ;
                   (по правилу — сначала количественные, потом качественные)
  fa_group_filter  считать только одну группу

Примеры формул:
  [Продано, шт.] * [Цена, руб.]                                 выручка (произведение)
  [Выручка, руб.] - [Себестоимость, руб.]                       маржа (сумма — для неё
                                                                 работает пропорциональное деление)
  [Выручка, руб.] / [Продано, шт.]                              средняя цена (кратная)
  [Объём] * ([Цена] - [Перем. затраты]) - [Пост. затраты]       прибыль (смешанная)
  [Рентабельность продаж] * [Оборачиваемость активов] * [Мультипликатор капитала]
                                                                 ROE по Дюпону (поля-коэффициенты)
Знаки: + - * / ( ) ^ (можно × ÷ −). Числа в формуле тоже можно: [Сумма] * 1,2

Какой метод к какой модели применим (плагин сам отключает лишние):
  цепные, абсолютные разницы, интегральный, Шепли — к любой модели;
  относительные разницы — только произведение a × b × c;
  индексный, логарифмический — произведения и частные;
  пропорциональное деление — когда в формуле есть сумма факторов.

Как считается: для каждой позиции отдельно, затем влияния складываются.
Позиции, которые появились или пропали между периодами, показываются
отдельными строками «Новые позиции» / «Выбывшие позиции» — так баланс
всегда сходится до рубля.


ЧТО НА ЧАРТЕ
------------

Кнопки «‹ раньше / позже ›» — сдвиг отчётного периода, «к пред. периоду /
к прошлому году» — база сравнения. Кнопки методов переключают основной метод.

  Итоги                — карточки, водопад влияния факторов, выводы текстом
  Все методы           — таблица «фактор × метод» с проверкой баланса и график
  Позиции              — крупнейшие изменения; щелчок по позиции открывает расчёт
  Расчёт по позиции    — «как в учебнике»: условные показатели и формулы метода
  Устойчивость и       — как влияние зависит от порядка подстановки (все порядки, до 6 факторов),
  чувствительность       эластичности и сценарии «фактор ±10%»


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------

* «В датасете нет полей: …» — название в Params не совпадает с датасетом
  (лишний пробел, другая буква). Ошибка перечисляет поля, которые есть.
  Если DataLens сам ругается на Sources — та же причина или неверный ID в Meta.
* «Датасет вернул 0 строк» — проверьте ID датасета в Meta и доступ к датасету.
* «Не удалось распознать периоды» — в поле периода не даты. Сделайте поле
  типа «Дата» в датасете.
* «Нет данных для периода сравнения» — например, сравнение с прошлым годом,
  а данных за прошлый год нет. Переключитесь на «к пред. периоду».
* Странные суммы цен — в датасете у цены агрегация «Сумма»; поставьте «Среднее».
* Чарт долго строится — очень много позиций. Отфильтруйте датасет или
  задайте fa_group_filter.
