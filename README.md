# Детерминированный факторный анализ на R

`deterministic_factor_analysis.R` — один файл, только базовый R (≥ 3.5), без обязательных пакетов.
Раскладывает изменение результативного показателя на влияние факторов всеми классическими методами
элиминирования, сверяет методы между собой, проверяет баланс и строит графики.

## Быстрый старт

```bash
Rscript deterministic_factor_analysis.R                        # демо: выручка = Ч × Д × П × В
Rscript deterministic_factor_analysis.R --demo=all             # все 7 демо
Rscript deterministic_factor_analysis.R --data=examples/example_wide.csv --model="V = CR*D*P*CV"
Rscript deterministic_factor_analysis.R --config=examples/my_config.R
Rscript tests/test_dfa.R                                       # проверки корректности
```

Из R:

```r
DFA_NO_RUN <- TRUE
source("deterministic_factor_analysis.R", encoding = "UTF-8")

res <- dfa_analyze("Y = a * b", base = c(a = 100, b = 10), report = c(a = 120, b = 12))
res <- dfa_analyze("PR = Q * (P - V) - F", data = my_df, main_method = "integral")
res$results[[1]]$effects      # матрица «фактор × метод»
res$tables$effects_long       # всё в длинном формате
```

Результаты сохраняются в `dfa_output/`: `dfa_report.txt`, `tables/*.csv` (с BOM, открываются в Excel),
`plots/*.png`, `dfa_plots.pdf` (все графики в одном файле), `dfa_results.rds`, а при установленном
`openxlsx` ещё и `dfa_results.xlsx`.

## Модели

Модель задаётся строкой `"Y = ..."`, формулой `Y ~ ...` или R-функцией. Подходит любое выражение R.

| Тип | Пример | Определяется автоматически |
|---|---|---|
| Аддитивная | `C = M + W + A + O` | да |
| Мультипликативная | `V = CR * D * P * CV` | да |
| Кратная | `R = P / (F + E) * 100`, `Y = a / b` | да |
| Смешанная | `PR = Q * (P - V) - FC` | да |
| Произвольная | `Y = k * sqrt(K) * L^0.6 * exp(g)` | да |
| Функция-«чёрный ящик» | `function(a, b) { ... }` | да |

* `constants = list(k = 1.5)` — константы, которые не считаются факторами.
* `submodels = list(b = "d * e")` — многоуровневая модель: фактор `b` раскрывается в `d * e`.

## Методы

| Код | Метод | Где применим |
|---|---|---|
| `chain` | Цепных подстановок | любая модель |
| `abs_diff` | Абсолютных разниц (с формулами) | мультипликативная |
| `rel_diff` | Относительных разниц | мультипликативная |
| `index` | Индексный | мультипликативная и кратная вида c·Πxᵖ |
| `integral` | Интегральный (квадратура Гаусса—Лежандра, аналитические или численные производные) | любая дифференцируемая |
| `log` | Логарифмический | c·Πxᵖ, индексы > 0 |
| `shapley` | Взвешенных конечных разностей / Шепли (среднее по всем порядкам) | любая |
| `proportional` | Пропорционального деления / долевого участия | суммы факторов внутри любой модели |

Если метод к модели или данным не подходит, он не ломает расчёт: в отчёте будет сказано, почему он пропущен.
Для каждого метода проверяется, что Σ влияний = ΔY.

Первые четыре метода зависят от порядка подстановки. Задать его можно тремя способами:
`order = "model"` (как в формуле), `order = "auto"` (сначала количественные, потом качественные,
по `factor_types`) или явным вектором `order = c("a", "b", "c")`. Скрипт перебирает все перестановки
(для k > 8 берёт случайную выборку), показывает разброс влияния каждого фактора и предупреждает,
если у какого-то фактора знак влияния зависит от порядка.

## Данные

* **wide**: строки — периоды, столбцы — факторы (`examples/example_wide.csv`, `example_periods.csv`).
* **long**: строки — факторы, столбцы — периоды (`examples/example_long.csv`). Формат определяется сам.
* **группы**: столбец с объектами (`examples/example_groups.csv`) находится автоматически или задаётся через `group_col`.
* CSV с `;` или `,`, десятичная запятая, пробелы в тысячах; также XLSX (через `readxl`/`openxlsx`) и RDS.
* Если в данных есть столбец с результатом (`V`, `Y`, …), он сверяется с расчётом по модели.

Схемы сравнения (`compare`): `first_last`, `chain` (цепная + итог за весь период),
`fixed_base` (базисная) и `custom` (`base_period` / `report_period`).

## Графики

Сводная панель, каскадная диаграмма (водопад), влияние факторов, структура влияния в % от ΔY,
сравнение методов, чувствительность к порядку подстановки, цепочка условных показателей,
темпы прироста факторов, эластичности, торнадо (±N %). Для нескольких периодов добавляются
вклады факторов по периодам, динамика результата и тепловая карта; для групп — сравнение объектов
и тепловая карта. Набор настраивается через `plot_types`, цвета — через `colors`, размер и dpi —
через `png_width` / `png_height` / `png_dpi`.

## Настройки

Все параметры с комментариями лежат в списке `CONFIG` в начале скрипта. Их можно поменять прямо там,
передать в `dfa_run(list(...))` / `dfa_analyze(..., param = value)` или вынести в отдельный файл-конфиг
(см. `examples/my_config.R`).

Кириллица: на Linux/macOS запускайте в UTF-8 локали; на Windows нужен R ≥ 4.2, а при `source()`
указывайте `encoding = "UTF-8"`.
